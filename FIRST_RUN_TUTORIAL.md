# First-run tutorial (new users)

Show once (skippable). Max 4 short steps, controller-friendly. Plain language.

1. **Welcome** — Orbit Shell is a home screen for Steam + a few shortcuts. It does not install games.
2. **Move & open** — D-pad/stick moves focus. **A** opens. **B** goes back / Desktop on home.
3. **Steam** — Dock Steam = Big Picture. Carousel games launch directly.
4. **Your stuff** — Point to ES-DE / Stremio / Grok / SD folder (optional). Export config anytime.

Empty Steam → friendly empty state + “Open Steam”. Offline → Retry / Use cache. Never trap the user.
